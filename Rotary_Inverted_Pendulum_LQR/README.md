# Rotary Inverted Pendulum — LQR

A linear quadratic regulator experiment for the rotary inverted pendulum in MuJoCo.

## Run

Install the dependencies from the repository root using `python -m pip install -r requirements.txt`, then run:

```sh
python Rotary_Inverted_Pendulum_LQR/Rotary_Inverted_Pendulum_LQR.py
```

The shared model is resolved relative to the script, so it does not need to be copied into this folder. A graphical desktop is required for the viewer. Review controller settings and simulation duration in the script before running it.

## Project documentation

See the [main README](../README.md) for the model, dependencies, recorded demonstrations, and project scope. These scripts are educational experiments; reproduce and assess results for your chosen configuration.
